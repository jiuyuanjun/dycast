当前未完善 / 需关注的功能点

  • 通知设置页：电池优化白名单、自启动/后台运行设置、保活引导依赖系统级 API 跳转，部分国产定制系统可能无法正确打开对应设置页。
  • 通知推送：在华为、小米、OPPO、vivo 等定制 ROM 上，后台推送可能被系统限制或延迟，需用户手动开启自启动/电池白名单。
  • WebView 登录：抖音网页登录依赖系统 WebView 组件，若 WebView 版本过低或 Cookie 策略受限，可能导致登录态提取失败。
  • 礼物信息：必须登录抖音账号后才能显示礼物信息；未登录时礼物面板仅展示登录引导。
  • 深色模式：部分边框/分隔线在深色模式下对比度不足，已列入下一轮 App 修复计划（提亮深色边框变量），本预览稿与真机现状保持一致。
  • 首页最近进入：首次安装无最近记录时，首页下半部分较空，暂无空状态引导。
  • 横屏页面流程：与竖屏一致（连接直播间 → 确认主播 → 账号登录 → 三栏主界面）；设置页为一级 / 二级菜单，通知/控制台/保存/切换为横屏优化全屏页。
  • 模拟器说明：顶部双视图模拟器仅用于 UI 预览与交互演示，不涉及真实网络连接与消息推送，消息流为模拟数据。
  • 首页搜索主播：输入框下方「搜索主播」按钮为本轮新增设计，App 端将在下一版本实装。
  • 顶部安全区：已增加 12px 额外间距，但仍需在更多机型（尤其是挖孔/刘海屏）上实测确认效果。
